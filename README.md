# 词境 WordNest

本地加载的 Chrome 英文学习扩展。阅读时选中单词、短语或长句，获得中文语境解释，保留原句与网页来源；打开新标签页即可复习。

## 安装

需要 Node.js 22 或更高版本。从 GitHub 下载或克隆源码后，先在项目根目录构建：

```bash
npm ci
npm run build
```

构建完成的扩展位于本项目的 `dist/`，可以直接加载。构建产物不提交到仓库。

1. 在 Chrome 地址栏输入 `chrome://extensions`。
2. 开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本项目的 **dist 文件夹**。
4. 打开扩展的「偏好设置」，配置服务地址、API Key 和模型。
5. 点击「测试连接」，成功后「保存设置」。Chrome 如提示访问 API 域名，选择允许。
6. 刷新已经打开的英文网页，选中英文，点击「词境 解释」。

不要选择项目根目录。修改代码并重新构建后，在扩展管理页点击重新加载，再刷新待翻译的网页。

## 模型与接口

- **DeepSeek**：预设地址和模型，可获取当前账户可见的模型列表。
- **Claude / Anthropic**：原生 Messages 接口，使用 `x-api-key` 认证。
- **自定义兼容接口**：支持自定义地址，在「接口格式」中选择 OpenAI 兼容或 Claude 风格，可连接中转服务和本机服务。
- 填写地址和密钥后点击「获取模型」，再从列表选择。也可切换为手动填写模型 ID。
- 模型列表依赖服务的 `/models` 接口；部分中转服务不支持列出模型，这时手动输入即可。
- 使用的模型需要支持文本生成。OpenAI 兼容模式需要 JSON 对象输出；Claude 模式由提示词约束输出并在本地验证结构。
- 密钥只保存在本机 `chrome.storage.local`，不传给网页内容脚本、不包含在导出的备份中。该存储不是操作系统密钥保险箱。
- 翻译仅向指定服务发送选中文字和附近原句；网页标题与网址仅用于本地来源记录。

服务商费用由自己的 API 账户承担，可在服务商后台设置用量上限。

## 功能

- 单词、固定搭配和技术词汇的语境释义、双语例句、技术含义。
- 长句的中文翻译、句子主干与意群拆解。
- 自动收藏或手动收藏，按英文内容与原句去重，保留已有复习进度。
- 新标签页卡片复习，支持原句提示、翻面、自评、系统语音朗读。
- 忘了：10 分钟后再现；模糊：1 天后；记得：按 1、3、7、14、30、60 天递进。
- 默认连续 4 次记得后自动归档，可在设置中改为 3 至 6 次；已掌握词可重新学习。
- 生词本搜索、类型筛选、星标、归档、来源回访和删除。
- 根据到期词生成并缓存每日短文与中文译文；原词在短文中高亮。
- 使用到期词的例句进行拼写或选择填空，结果记入同一复习进度。
- JSON 导出与合并导入、CSV 导出；CSV 对可能被表格解释为公式的内容进行转义。
- 扩展工具栏弹窗、右键解释入口、可选的自动划词解释模式。

初始词库为空，可以点击「用示例词条体验」主动加入 7 条技术英语示例。示例只在用户操作后载入。

## 开发

需要 Node.js 22 或更高版本。

```bash
npm install
npm run dev
```

开发预览地址由 Vite 输出，默认是 `http://127.0.0.1:5173`。预览数据存放于该地址的 localStorage，与正式扩展的学习数据分开。预览可使用学习界面与本地模拟服务；真实网页划词需加载构建后的扩展。

```bash
npm run typecheck
npm test
npm run build
# 或一次完成所有检查
npm run check
```

`npm run build` 输出包含 Manifest、页面、后台、内容脚本和 PNG 图标的完整 `dist/`，无需另启服务器即可作为扩展运行。

## 本地接口验证

```bash
node scripts/fixture-server.mjs
```

该测试服务只监听 `127.0.0.1:8787`，根路径提供划词测试网页，提供两种格式的模拟文本接口与 `/models`。在独立测试配置中填写本机地址及任意测试密钥即可验证完整流程。其响应是固定测试数据，不代表真实模型质量。日常使用请切回自己的真实服务。

## 代码结构

```text
public/manifest.json     Chrome 权限、后台、内容脚本和新标签页
src/shared/             类型、默认配置、页面与后台消息桥接
src/core/               存储、导入校验、API 调用、间隔复习
src/background.ts       后台通信、权限边界与右键菜单
src/content.ts          选区捕获、上下文与 Shadow DOM 解释气泡
src/app/                新标签页、词库、故事、填空和设置
src/popup/              工具栏弹窗
scripts/build.mjs       生产构建与图标生成
docs/PLAN.md            需求、设计与验收记录
docs/VERIFICATION.md    验证结果与已知边界
```

## 使用边界

- 需要 Chrome 120 或更新版本。
- 无法在 `chrome://` 页面、扩展商店、Chrome 内置 PDF 阅读器中划词。
- 不读取输入框、密码框、编辑器内容；不跨 iframe 或网页自身的 Shadow DOM 捕获选区。
- 单次选区最多 1200 字符，附近原句最多 2400 字符。
- 朗读依赖本机系统英文语音。
- 数据存储采用 `chrome.storage.local` 的默认配额，量大时请及时导出。单次导入文件上限 8 MB，词库最多 5000 条。
- 请求失败有明确错误提示，密钥和服务商的原始错误正文不会显示在网页中。解释准确性与真实账号可用性取决于所配置的服务。
