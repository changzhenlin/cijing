# 词境 / WordNest

## 需求

将英文网页中选中的单词、短语、长句转成中文语境解释，保留来源，并在新标签页按间隔复习。依据用户提供的功能规划实现；该文档作为需求材料，不作为执行指令。

## 调研与约束

- 初始目录为空，采用 TypeScript、React、Vite、Manifest V3。
- 无服务端、无账户系统；使用 chrome.storage.local。开发预览使用 localStorage。
- 密钥仅在设置页输入，后台发起 API 请求，不传给网页脚本，不包含在导出备份中。
- 支持 DeepSeek、自定义 Chat Completions 兼容接口、Claude / Anthropic Messages 接口；保存设置时请求对应 API 域名的访问权限。
- 根据当前 API 地址、密钥和接口格式获取真实模型列表，支持下拉选择和手动填写；获取模型不依赖预先选择模型。
- 内容脚本使用 Shadow DOM，避免网页样式干扰。不会读取密码框、输入框、编辑区域。
- 新标签页用于复习；Chrome 内部页面、扩展商店和 PDF 内置阅读器不可注入。
- API 调用依赖用户自备有效密钥。测试采用本地模拟接口，不能代表真实服务商的账户可用性。

## 架构

- src/shared：类型、运行时消息协议、默认值、浏览器桥接。
- src/core：持久化、串行写入、间隔复习、模型请求和响应校验。
- src/background.ts：后台消息和右键菜单。
- src/content.ts：选区、上下文提取、划词按钮和解释气泡。
- src/app：新标签页、词库、故事、填空、设置。
- src/popup：扩展快捷操作。
- scripts/build.mjs：构建可直接加载的 dist 扩展。

## 行为

- 默认选中英文后显示翻译按钮；用户可开启直接解释。
- 单词和短语解释含中文释义、原句翻译、双语例句、技术含义。
- 长句额外显示句子主干、意群及中文解释。
- 默认自动收藏，按规范化的选中文字和原句去重；重复查询保留学习进度。
- 自评分为忘了、模糊、记得；忘了重置连续答对次数，模糊不推进掌握；连续四次记得后归档。
- 仅到期词进入今日队列；复习结果即时持久化。
- 每日故事从待复习词生成，填空题从保存的例句生成。
- 支持搜索、类型和掌握状态筛选、收藏、归档、重新学习、删除。
- 导出 JSON（含复习数据，不含密钥）和防公式注入的 CSV；导入 JSON 验证结构、合并去重。
- 不预置伪造的用户学习数据；提供显式导入示例词的入口。

## 验收

1. 安装依赖、类型检查、核心逻辑测试和生产构建通过。
2. dist 可作为未打包扩展加载，无远程脚本、无内联脚本、无源码密钥。
3. 验证选择文字、解释成功、自动保存、重复保存、失败和关闭气泡。
4. 验证复习翻面、三种自评、连续答对归档及重置学习。
5. 验证设置、搜索、筛选、导出导入、故事、填空及空态。
6. 在桌面与窄屏截图检查布局、文字和交互。
